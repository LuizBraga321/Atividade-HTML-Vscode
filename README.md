# Luiz Braga de Menezes Neto

Este projeto foi criado como atividade de HTML. Ele apresenta informações pessoais, contatos, fotos e vídeos do YouTube.

## Arquivos

- `index.html`: página inicial com apresentação, formação, área de atuação e contatos.
- `biografia.html`: página com biografia, foto, time do coração, hobby e vídeo favorito.

## Tecnologias utilizadas

- HTML5
- Links, listas e imagens
- Vídeos do YouTube
